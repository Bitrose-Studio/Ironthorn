- The editor's panels dock, and layouts can be saved, loaded, set as the default, deleted and
  reset from the Window menu or by the `ith.window.*` commands and automation scripts. The editor
  restores the last session's layout at start-up and keeps it in the project's `Saved/Editor`
  folder; saved layouts live in the user's configuration folder.
- The Output Log panel shows the engine's log with a level filter and a search box.
- The engine's `Layouts/Default.json` uses `left_right` and `top_bottom` splits and marks its
  central area; `Editor.json` names the default layout in `layouts.defaultName`.
